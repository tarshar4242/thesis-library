# 🀄 台式十六張麻將

支援「單人對 AI」與「同一個 Wi-Fi 下好友連線對戰」的網頁麻將。

## 這個資料夾怎麼來的

- `public/` 裡的 `index.html`、`style.css`、`client.js`：從原本跑在 `192.168.1.104:4100` 的遊戲**原封不動**下載保存。
- `server.js`、`game.js`：原版伺服器程式拿不到，依照 `client.js` 的通訊方式**重新寫出來**。規則與台數照遊戲內「規則/台數」表實作，細節可能和原版略有差異。

## 在 Mac 上啟動（第一次）

1. 安裝 Node.js：到 <https://nodejs.org> 下載 LTS 版，一路按「繼續」裝好。
2. 打開「終端機」，切到這個資料夾（輸入 `cd ` 加一個空白，再把資料夾拖進終端機，路徑會自動填好）：
   ```bash
   cd 這裡是資料夾路徑
   ```
3. 安裝套件（只有第一次要做）：
   ```bash
   npm install
   ```
4. 啟動遊戲：
   ```bash
   npm start
   ```
5. 用瀏覽器打開 <http://localhost:4100> 就能玩。

## 邀請好友

啟動後終端機會印出「區網好友」的網址（例如 `http://192.168.1.152:4100`），大廳下方也看得到。好友連同一個 Wi-Fi，用瀏覽器打開這個網址，輸入你建立的房號就能加入。空位開局時由電腦補上。

## 關掉遊戲

在終端機按 `Control + C`。

## 規則摘要

- 144 張（含 8 張花牌），每人 16 張，胡牌為 5 組面子加 1 對眼。
- 只能吃上家的牌；優先順序：胡 > 碰/槓 > 吃。
- 計分為「底 1 台 1」：一局得分 = 1 + 台數；自摸三家各付，放槍由放槍者付。
- 莊家胡牌或流局連莊，否則換莊，莊家輪一圈換風圈。
- 真人 20 秒沒回應吃碰胡會自動「過」；牌局中斷線改由電腦代打。

## 測試

```bash
npm test
```

讓四台電腦自動連打 60 局，檢查牌數不會多也不會少、台數計算正確。
