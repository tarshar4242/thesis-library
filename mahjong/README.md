# 🀄 台式十六張麻將

支援「單人對 AI」與「同一個 Wi-Fi 下好友連線對戰」的網頁麻將。

## 這個資料夾怎麼來的

- `original/`：從原本跑在 `192.168.1.104:4100` 的遊戲下載的 `index.html`、`style.css`、`client.js`，**原封不動**留底。
- `public/`：實際使用的前端，以原檔為基礎，加上「聽牌」按鈕、聽牌標記、連莊顯示，並把規則表換成明星3缺1 的台數。
- `server.js`、`game.js`：原版伺服器程式拿不到，依照 `client.js` 的通訊方式**重新寫出來**。台數依明星3缺1 官網公布的「見花見字」台數表實作。

## 在 Mac 上啟動（第一次）

1. 安裝 Node.js：到 <https://nodejs.org> 下載 LTS 版，一路按「繼續」裝好。
2. 打開「終端機」，切到這個資料夾（輸入 `cd ` 加一個空白，再把資料夾拖進終端機，路徑會自動填好）：
   ```bash
   cd 這裡是資料夾路徑
   ```
3. 安裝套件（只有第一次要做）：
   ```bash
   npm install
   ```
4. 啟動遊戲：
   ```bash
   npm start
   ```
5. 用瀏覽器打開 <http://localhost:4100> 就能玩。

## 邀請好友

啟動後終端機會印出「區網好友」的網址（例如 `http://192.168.1.152:4100`），大廳下方也看得到。好友連同一個 Wi-Fi，用瀏覽器打開這個網址，輸入你建立的房號就能加入。空位開局時由電腦補上。

## 關掉遊戲

在終端機按 `Control + C`。

## 規則摘要（參考明星3缺1）

- 144 張（含 8 張花牌），每人 16 張，胡牌為 5 組面子加 1 對眼。
- 只能吃上家的牌；優先順序：胡 > 碰/槓 > 吃。
- **見花見字**：每張花 1 台、每組風牌刻子 1 台，不看座位；湊齊春夏秋冬或梅蘭竹菊再加 2 台；八張花全拿直接喊胡（八仙過海 8 台）。
- **聽牌宣告**：按「聽牌」再選一張發亮的牌打出。宣告後手牌鎖住，只能打摸進的牌。莊家第一張就聽是天聽 8 台；海底打進八張內、四家都沒吃碰槓是地聽 4 台；其他時候聽牌 1 台。天聽、地聽能胡不胡（過水）就降為一般聽牌。
- **計分「底 1 台 1」**：一家付的點數 = 1 + 台數。自摸三家各付，放槍由放槍者付。
- **莊家與連莊**：莊家胡牌或放槍都多算 1 台；連 N 拉 N 再加 2N 台。非莊家自摸時，只有莊家多付這些台。莊家胡牌或流局連莊，最多連 10 次。
- 真人 20 秒沒回應吃碰胡會自動「過」；牌局中斷線改由電腦代打。
- 台數表依據：[明星3缺1 台數計算（遊戲橘子官網）](https://www.gametower.com.tw/Games/Freeplay/MJ/Star31/Data/count.aspx)
