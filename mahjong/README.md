# 🀄 台式十六張麻將

支援「單人對 AI」、「同一個 Wi-Fi 下好友連線」與「放上雲端跟各地好友對戰」的網頁麻將。

## 這個資料夾怎麼來的

- `original/`：從原本跑在 `192.168.1.104:4100` 的遊戲下載的 `index.html`、`style.css`、`client.js`，**原封不動**留底。
- `public/`：實際使用的前端，以原檔為基礎，加上聽牌、連莊顯示、明星3缺1 規則表、封面改版、公仔與特效（`fx.js`）、公仔圖（`img/`）。
- `server.js`、`game.js`：原版伺服器程式拿不到，依照 `client.js` 的通訊方式**重新寫出來**。台數依明星3缺1 官網公布的「見花見字」台數表實作。

## 畫面與聲音

- **封面**：預設「喜氣紅金」，網址加 `?theme=cream`（奶茶米白）或 `?theme=jade`（翡翠綠）可切換。最下方是品牌「Learn AI with Tarshar🍀|2026」。
- **公仔**：座位 1（房主）是 Tarshar 的京劇公仔，其他座位是招財貓、熊貓、小老虎。輪到誰，誰的公仔就搖頭晃腦；吃碰槓聽胡會冒對話框。
- **特效**：喊牌時畫面中間跳出大字；胡牌時贏家喊「發財啦！」、放槍的人冒冷汗，滿天彩帶。
- **設定（⚙️）**：音效、語音喊牌、背景音樂（國樂古箏／過年鑼鼓／輕鬆爵士）、氣氛（可愛／過年）。設定記在各自的瀏覽器裡。
- 背景音樂和音效都是程式即時合成，不使用外部音樂檔，沒有版權問題。

## 新手教練「碰碰」🐦

給不會打麻將的人：大廳按「🔰 新手教練模式」（或在 ⚙️ 設定裡開），一隻戴哨子的小麻雀會站在場邊陪你打。

- **輪到你出牌**：標亮建議打的那張（🐦打這張），說明為什麼、離聽牌還差幾步、哪些牌能幫你。
- **能吃碰槓胡時**：告訴你該不該吃碰，碰了會少什麼台。
- **聽牌時**：告訴你聽哪幾張、場上還剩幾張、大約幾成機會胡。
- **看別人**：誰在做一色、誰快胡了，有人聽牌時優先挑「現物」（他打過的牌）來打。
- **名詞小教室**：面子、眼、聽牌、現物、門清…第一次出現時附白話解釋，學過的不再重複。
- **語音**：開著語音時會唸出來。手機上說完話會自動縮成小頭像，點一下就展開。
- **公平**：碰碰只看你自己的手牌和桌上公開的牌，不會偷看別人的牌。

### 碰碰的 AI 功能（選用）

沒有設定也能用：碰碰會用內建的台詞給建議。設定 Claude API 金鑰後，碰碰的話會更生動，還能回答你打字問的問題。

1. 到 Render 後台，點 `tarshar-mahjong` 服務，左側選 **Environment**。
2. 新增 `ANTHROPIC_API_KEY`，值貼上你的 Claude API 金鑰，按 **Save Changes**。服務會自動重新啟動。
3. 如果金鑰沒有綁定工作區（Workspace），再新增 `ANTHROPIC_WORKSPACE_ID`，值是 Claude Console 裡工作區的 ID（`wrkspc_` 開頭）。
4. 回到遊戲，碰碰對話框下方出現「問碰碰」輸入框，就代表 AI 已經啟用。打開 `/api/coach-health` 可以看到 AI 最近一次成功或失敗的原因（不會顯示金鑰）。

保護額度的機制：金鑰只存在伺服器、每位玩家 5 秒內最多問一次、每天總共最多 300 次（`COACH_DAILY_LIMIT` 可調）。AI 沒回應或額度用完時，自動改用內建台詞，不影響遊戲。預設模型是 `claude-opus-5-5`，可用環境變數 `COACH_MODEL` 更換。

## 在 Mac 上啟動（第一次）

1. 安裝 Node.js：到 <https://nodejs.org> 下載 LTS 版，一路按「繼續」裝好。
2. 打開「終端機」，切到這個資料夾（輸入 `cd ` 加一個空白，再把資料夾拖進終端機，路徑會自動填好）：
   ```bash
   cd 這裡是資料夾路徑
   ```
3. 安裝套件（只有第一次要做）：
   ```bash
   npm install
   ```
4. 啟動遊戲：
   ```bash
   npm start
   ```
5. 用瀏覽器打開 <http://localhost:4100> 就能玩。

## 邀請好友

啟動後終端機會印出「區網好友」的網址（例如 `http://192.168.1.152:4100`），大廳下方也看得到。好友連同一個 Wi-Fi，用瀏覽器打開這個網址，輸入你建立的房號就能加入。空位開局時由電腦補上。

## 放上雲端（Render，好友不必同一個 Wi-Fi）

專案根目錄的 `render.yaml` 已經設定好，Render 會自動找到 `mahjong/` 資料夾並啟動。

1. 到 <https://render.com> 用 GitHub 帳號登入。
2. 右上角 **New +** → **Blueprint**。
3. 選 `thesis-library` 這個專案，按 **Connect**。
4. 確認服務名稱是 `tarshar-mahjong`、方案是 **Free**，按 **Deploy Blueprint**。
5. 等 2 到 3 分鐘，網址就會是 `https://tarshar-mahjong.onrender.com`（名字被別人用走時，Render 會自動加上幾個字）。

免費方案 15 分鐘沒人連線會休眠，下一個人打開要等約 30 秒到 1 分鐘；休眠或更新時，進行中的牌局和分數會清掉。之後程式推上 `main`，Render 會自動重新部署。

## 關掉遊戲

在終端機按 `Control + C`。

## 規則摘要（參考明星3缺1）

- 144 張（含 8 張花牌），每人 16 張，胡牌為 5 組面子加 1 對眼。
- 只能吃上家的牌；優先順序：胡 > 碰/槓 > 吃。
- **見花見字**：每張花 1 台、每組風牌刻子 1 台，不看座位；湊齊春夏秋冬或梅蘭竹菊再加 2 台；八張花全拿直接喊胡（八仙過海 8 台）。
- **聽牌宣告**：按「聽牌」再選一張發亮的牌打出。宣告後手牌鎖住，只能打摸進的牌。莊家第一張就聽是天聽 8 台；海底打進八張內、四家都沒吃碰槓是地聽 4 台；其他時候聽牌 1 台。天聽、地聽能胡不胡（過水）就降為一般聽牌。
- **計分「底 1 台 1」**：一家付的點數 = 1 + 台數。自摸三家各付，放槍由放槍者付。
- **莊家與連莊**：莊家胡牌或放槍都多算 1 台；連 N 拉 N 再加 2N 台。非莊家自摸時，只有莊家多付這些台。莊家胡牌或流局連莊，最多連 10 次。
- 真人 20 秒沒回應吃碰胡會自動「過」；牌局中斷線改由電腦代打。
- 台數表依據：[明星3缺1 台數計算（遊戲橘子官網）](https://www.gametower.com.tw/Games/Freeplay/MJ/Star31/Data/count.aspx)

## 測試

```bash
npm test
```

先驗證每一種台型的計算，再讓四台電腦自動連打 60 局，檢查牌數不會多也不會少、聽牌宣告合法、分數加總為零。接著測碰碰：建議是否合理、有沒有偷看別人的牌、AI 串接格式與失敗退回，以及照碰碰建議打是否比亂打更常胡牌。
