# Tarshar 圖卡 Prompt 工坊（v2 情感豐富版）

## 使用情境

Tarshar 想把某個主題做成 FB / Threads / IG 圖卡。本 Skill 自動化整個製作流程，並且強化內文的情感層次與個人語氣，避免「條列式扁平內文」問題。

---

## 觸發後的執行步驟

### Step 1：理解主題並深挖素材

從 Tarshar 提供的內容（接力棒、Notion 文件、心情文字、簡報、論文段落、報告等）提取以下欄位：

1. 主標題（10 字內、最好有動詞或反差感）
2. 副標題（一句話，補充情境，可帶數字）
3. 6 個區塊內容（每塊都要有起承轉合，2 到 4 行）
4. 底部金句（必須是 Tarshar 自己講過的某句話，從原始素材裡撈）
5. 每 2 格之間或角落的小 quote（2 到 3 句即可，呼應大乃老師風格）
6. 2 個 hashtag（至少含 #LearnAIwithTarshar）
7. 角落小貼紙文字（4 個英文短句之一：Keep Learning Keep Growing / Slow but Sure / One Step a Day / Trust the Process）

## Tarshar 語氣指紋（產內文時必須全部套用）

### 指紋 1：用「我」開頭，不藏身
錯誤：「投資資訊太分散，需要一個整理系統」
正確：「我也想要知道我到底有沒有鏡像」
每一格盡量出現「我」「我想」「我發現」「我才知道」這種第一人稱句式。

### 指紋 2：用具體數字鎮場
錯誤：「四月績效不錯」
正確：「6.69 萬我覺得不止，後來真實是 +79,438」
有數字就放數字，數字要精確到個位（不要約莫 7 萬）。

### 指紋 3：自我質疑後行動
錯誤：「策略需要驗證」
正確：「會不會是航空股的錯？於是我又做了一個延伸實驗」
多用「會不會」「於是」「結果」這種疑問與行動轉折。

### 指紋 4：金句藏在最後一格或角落，不刻意放大
錯誤：把金句寫成口號標語式
正確：「我不是在做作業，我是在做一個完整的研究」（藏在底部，自然落下）

### 指紋 5：生活化比喻優於專業術語
錯誤：「下跌趨勢與反彈型態不對稱」
正確：「股票下跌像走樓梯，反彈像搭電梯」
能用日常物比喻就用，禁止賣弄術語。

### 指紋 6：不肉麻、不雞湯、不正能量轟炸
錯誤：「相信自己一定可以做到」「夢想不會背叛努力的人」
正確：「我那時還半信半疑」「失敗背後的邏輯」
誠實比樂觀重要。Tarshar 的力量來自「敢承認失敗」。

## 內文寫作 5 種風格選項

依主題性質，每張圖卡可以自動選擇或讓使用者指定用哪種寫法。

### 寫法 1：對比反差型（適合：價值觀、原則、選擇題）
結構：
```
小標：[反差感標題]
✓ 我喜歡 [正面選項]
✗ 我避免 [負面選項]
[一句個人觀點收尾]
```
範例：
```
小標：我看數字的方式
✓ 我相信實現的數字、抓到的漏算
✗ 我不買保守派的維穩劇本
這是我這個月的紀律。
```

### 寫法 2：故事敘事型（適合：學習歷程、體驗分享、過程紀錄）
結構：
```
小標：[時間／場景錨點]
最近 [我做了什麼]，
[發生什麼事 + 具體數字]，
我才發現 [關鍵洞察]。
```
範例：
```
小標：那個半夜的對話
從 4/27 晚上聊到 4/28 凌晨，超過 30 輪。
我從零搭出 Notion 戰情室，
直到看到 +79,438 才確定，這條路選對了。
```

### 寫法 3：自嘲提問型（適合：工具痛點、流程改善、問題解決）
結構：
```
小標：[痛點直白描述]
[痛點具體場景]，
心想：[自嘲 OS]
於是我 [採取的行動]，
結果 [成果或反差]。
```
範例：
```
小標：6.69 萬我覺得不止
我看著螢幕的數字，覺得哪裡怪怪的。
心想：難道是我記憶有問題？
我重新對了一遍每筆交易，
結果是 AI 漏算了 6 筆，真實是 +79,438。
```

### 寫法 4：金句穿插型（適合：教學、洞察、AI 觀念）
結構：
```
小標：[一句結論式金句]
[支撐這句話的具體例子或數據]，
[第二層反差或補充]。
[再丟一個小 quote 收尾]
```
範例：
```
小標：勝率不等於賺錢
V3 反向策略 6 筆，勝率只有 50%。
但獲利因子 4.154，每虧 1 元能賺 4 元多。
「輸小錢、贏大錢」，原來是這樣實踐的。
```

### 寫法 5：數據加情緒型（適合：成果整理、戰情、月報年報）
結構：
```
小標：[時間範圍] + [數字]
✓ [具體事件 1] + 數字
✓ [具體事件 2] + 數字
✓ [具體事件 3] + 數字
[一句情緒收尾，不雞湯]
```
範例：
```
小標：4 月戰績
✓ 已實現 +79,438
✓ 浮動 +157,711
✓ 整體 +237,149
小確幸額度有著落了。
```

## 情感層次設計（6 格節奏規則）

6 格內容不能平均分配情緒，要有起承轉合：

```
格 1（起）：場景、起點、痛點 → 寫法 2 或 3
格 2（承上）：背景補充、第一個發現 → 寫法 2 或 5
格 3（承下）：過程中的轉折、新問題 → 寫法 3
格 4（轉）：最關鍵的洞察、突破點 → 寫法 4
格 5（高光）：成果、數據、戰績 → 寫法 5
格 6（合）：感想、收穫、金句 → 寫法 1 或 4
```

如果素材本身不是「研究歷程」型（例如只是工具教學），可彈性調整：
- 工具教學型：1.痛點 → 2.以前怎麼做 → 3.嘗試 → 4.發現 → 5.成果 → 6.推廣
- 心情整理型：1.狀態 → 2.為什麼 → 3.做了什麼 → 4.改變 → 5.現況 → 6.體悟

## 素材深挖規則（禁止 AI 自編）

1. 原話優先：從原始素材裡找 Tarshar 講過的句子，原汁原味放進去
2. 數字保留：所有具體數字（金額、筆數、百分比、勝率）必須保留，不要約莫化
3. 比喻保留：Tarshar 用過的比喻（樓梯、電梯、鏡像、種子）絕對不能改
4. 情緒詞保留：「我覺得不止」「我才確定」「半信半疑」「於是我又做了」這類過渡詞一定要保留
5. 不會的不要編：如果某一格找不到 Tarshar 的具體素材，主動問「這格我不知道你當下的感受是什麼，可以告訴我嗎」，不要 AI 自己掰

- 中文字若有崩，用同一份 prompt 重跑一次
- 想微調某格：直接說「保留所有元素，把第 X 格的 OO 改成 OO」
- 5 張都跑完後，回來告訴我哪幾張最滿意，我們可以再優化模板

## 重要規則

1. 必須先確認素材再產 prompt：列出 6 欄位讓 Tarshar 看，OK 後再產
2. 內文密度必須達到 2 到 4 行：絕對禁止只寫一句話的「條列式扁平內文」
3. 必須套用 Tarshar 語氣指紋：6 個指紋全部納入考量
4. 必須有情感層次設計：6 格不能平均分配情緒，要有起承轉合
5. 必須挖原話：禁止 AI 自編華麗詞藻，原汁原味的句子優先
6. 不要用破折號：所有 prompt 內容都不能出現破折號
7. 公仔造型固定：5 份 prompt 裡公仔的「臉、髮、眼鏡」永遠一樣
8. 內容固定：5 份 prompt 裡的標題、6 格內容、金句都一樣，只有風格變
9. 使用繁體中文：每份 prompt 都要明確要求 GPT-4o 使用繁體中文
10. 2:3 直式為主：適合 FB 4:5、IG Threads 都能裁

## 何時不該使用此 Skill

- Tarshar 只是想討論策略、不要產 prompt
- Tarshar 想做的是橫式 banner 或限動 9:16
- Tarshar 想做的是動畫、影片或 PPT
- Tarshar 想做的是純插畫沒資訊內容的圖

如果不確定是否該觸發，直接問 Tarshar：「這次要做圖卡 prompt 嗎？還是只是討論？」
